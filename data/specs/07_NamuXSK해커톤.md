# 프로젝트 개요
SK Intellx에서 추진 중인 웰니스 로보틱스 **NamuX A1 공기청정기**를 주제로  
관련 서비스를 개발하는 해커톤에 참가하여 **앱 개발자 역할**을 수행한 프로젝트입니다.  

공기청정기와 연동되는 애플리케이션을 제작하여  
사용자가 실내 공기 상태를 확인하고 관리할 수 있도록 기능을 구현했습니다.  

프로젝트 결과 우수한 평가를 받아 **우수상**을 수상하였으며,  
이후 해당 아이디어를 기반으로 **대학생 최초 SK POC(Proof of Concept)**가 진행되었습니다.

---

## 주요 기능

- 공기청정기 상태 확인 기능
- 실내 환경 데이터 시각화
- 사용자 중심 공기질 모니터링 UI
- 기기 연동 기반 제어 기능 설계
- 웰니스 서비스 아이디어 구현
