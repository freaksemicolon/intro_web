# 프로젝트 개요
GIST의 핵심 딴짓 프로젝트인 **무한도전 프로그램**에 Rootive 팀 개발자로 참여하여  
팔루다리움 제작과 Python 기반 컴퓨터 시뮬레이션 개발을 수행한 프로젝트입니다.  

실제 식물 생태 환경을 구현한 팔루다리움을 제작하고,  
이를 분석하고 관리하기 위한 **컴퓨터 시뮬레이션 프로그램**을 함께 개발했습니다.  
환경 변화에 따른 식물 상태를 예측하고 시각적으로 확인할 수 있도록 설계하였습니다.

---

## 주요 기능

- 팔루다리움 환경 구축
- 식물 생태 환경 설계
- Python 기반 시뮬레이션 구현
- 환경 변수 기반 상태 분석
- 시뮬레이션 결과 시각화
- 실제 환경과 디지털 모델 연동
