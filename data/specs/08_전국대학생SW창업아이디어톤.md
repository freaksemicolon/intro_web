# 프로젝트 개요
대학 창업팀 **Rootive**의 개발 리더로 참여하여  
식물 가드닝 서비스를 위한 **웹 페이지 및 모바일 앱 플랫폼**을 개발한 프로젝트입니다.  

사용자가 식물을 보다 쉽게 관리할 수 있도록  
가드닝 정보 제공, 식물 상태 관리, 서비스 연동 기능 등을 중심으로 설계하였으며  
프로젝트의 전체 개발 방향과 기술 구현을 총괄하였습니다.

---

## 주요 기능

- 식물 가드닝 정보 제공 기능
- 사용자 식물 관리 기능
- 웹 기반 서비스 플랫폼 구축
- 모바일 앱 연동 기능 설계
- 사용자 중심 UI/UX 설계
- 서비스 확장 고려 구조 설계

- 개발 리더 (Development Lead)

- 전체 개발 구조 설계
- 팀 개발 일정 조율
- 기능 정의 및 기술 선택
