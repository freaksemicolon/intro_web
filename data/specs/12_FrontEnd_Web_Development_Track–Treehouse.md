# 프로젝트 개요
Treehouse의 **Front End Web Development Track**을 수강하여  
HTML, CSS, JavaScript 기반 프론트엔드 웹 개발 전반을 학습한 과정입니다.  

반응형 웹 디자인, UI 구현, 인터랙션 개발 등  
실제 웹 페이지 제작 중심의 실습을 통해  
프론트엔드 개발 기초 역량을 강화하였습니다.

---

## 학습 내용

- HTML 구조 설계
- CSS 스타일링 및 레이아웃
- 반응형 웹 디자인
- JavaScript 기초 문법
- DOM 조작
- 인터랙션 구현
- 웹 접근성 기초

## 수행 활동

- 웹 페이지 레이아웃 제작
- UI 컴포넌트 구현

- 반응형 웹 구현 실습
- 프로젝트 기반 학습 수행
