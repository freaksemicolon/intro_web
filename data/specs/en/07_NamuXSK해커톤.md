# Overview

I participated as an app developer in a hackathon focused on the NamuX A1 wellness air purifier. We designed an application that helps users understand indoor-air conditions and interact with the device.

## My Contribution

- Designed service features and user flows
- Implemented the mobile interface
- Developed concepts for device integration and air-quality visualization

## Outcome

- Received an Excellence Award
- Advanced to SK's first university-student proof-of-concept project
