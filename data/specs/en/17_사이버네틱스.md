# Overview

During a two-month development internship, I designed and implemented a web-based control and management system for a SPIM microscopy environment. I built a Django interface, connected experiment-management workflows, and prepared an internal server environment for operation and validation.

## Responsibilities

| Area | Contribution |
| --- | --- |
| Design | Organized key states and management workflows for the SPIM environment |
| Web development | Implemented the Django interface and management features |
| Server | Configured the internal server and runtime environment |
| Validation | Tested user flows and incorporated improvements |

## Problem-Solving Process

1. Identified recurring work and required information in the experiment workflow.
2. Translated equipment-oriented concepts into an understandable interface structure.
3. Connected the interface and management logic with Django.
4. Tested the system in the internal server environment.
5. Refined features and feedback based on validation results.

## Outcome

- Implemented a web-based management system for the SPIM experiment environment
- Improved the usability of research-equipment workflows
- Gained hands-on server deployment and operation experience
