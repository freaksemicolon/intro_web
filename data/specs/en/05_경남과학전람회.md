# Overview

I built a perceptual computer interface that uses camera-based hand tracking to replace conventional mouse and keyboard input. The system combines MediaPipe, speech recognition, speech synthesis, and real-time translation.

## Key Features

- Gesture-based pointer movement, clicking, dragging, and scrolling
- Virtual keyboard input using finger position and pose
- Speech-to-text, text-to-speech, and voice commands
- Real-time language detection and translation

## My Contribution

I designed and implemented the gesture interface, mouse control, virtual keyboard, speech features, translation workflow, and overall system integration.

## Technologies

Python, MediaPipe Hands, OpenCV, STT, TTS
