# 프로젝트 개요
아두이노와 환경 센서를 활용하여 식물의 상태를 분석하고  
이를 웹 페이지에서 실시간으로 확인할 수 있는 **IoT 식물 관리 시스템**을 개발한 프로젝트입니다.  

토양 수분, 환경 정보 등을 센서로 수집하고 해당 데이터를 기반으로  
식물의 물 부족 여부 및 상태를 분석하여 웹 인터페이스에서 시각적으로 표현하도록 설계했습니다.  

프로젝트에서 **개발 리더 역할**을 맡아 전체 구현 방향을 설계하였으며,  
특히 **웹 페이지 제작과 아두이노-웹 간 통신 기능 구현**을 중심적으로 담당했습니다.

---

## 주요 기능

- 식물 환경 데이터 센서 측정
- 토양 수분 기반 물 부족 판단
- 실시간 식물 상태 웹 표시
- IoT 기반 아두이노 데이터 수집
- 센서 데이터 시각화 UI
- 상태 알림 기능

---

## 내가 수행한 역할

- 개발 리더 (Development Lead)
- 웹 페이지 UI/UX 설계 및 구현
- 아두이노 센서 데이터 통신 구현
- 센서 데이터 웹 표시 로직 구현
- 식물 상태 판단 로직 설계
- 팀 개발 방향 조율

---

## 사용 기술

- Arduino
- 환경 센서 (토양 수분 등)
- Web Frontend
- IoT 통신
- 실시간 데이터 처리
