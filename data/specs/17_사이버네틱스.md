# 프로젝트 개요
사이버네틱스이미지시스템스에서 **2개월간 개발 인턴**으로 근무하며  
SPIM 현미경 실험 환경을 위한 웹 기반 제어 및 관리 시스템을 설계하고 구현했습니다.  

실험 장비 사용 편의성을 높이기 위해 Django 기반 사용자 인터페이스를 개발하고,  
실험 환경 관리 및 제어 기능을 웹에서 수행할 수 있도록 시스템을 구축했습니다.  
또한 사내 서버 환경 구축을 통해 서비스 운영 기반을 마련했습니다.

## 문제 정의

SPIM 현미경 실험은 장비 상태와 실험 환경을 함께 관리해야 합니다. 기존 작업 흐름에서는 장비를 직접 다루는 과정과 실험 정보를 확인하는 과정이 분리되어 있어, 사용자가 여러 단계를 오가야 했습니다.

이 프로젝트의 목표는 단순히 화면을 하나 만드는 것이 아니라 다음 질문에 답하는 것이었습니다.

- 실험자가 장비 상태와 필요한 정보를 한 화면에서 이해할 수 있는가?
- 반복적인 관리 작업을 웹 인터페이스로 단순화할 수 있는가?
- 사내 환경에서 안정적으로 실행하고 개선할 수 있는 운영 기반이 있는가?

## 담당 역할

개발 인턴으로서 요구사항을 정리하고 Django 기반 웹 인터페이스와 관리 기능을 구현했습니다. 화면 개발뿐 아니라 사내 서버 환경을 구성하고 실제 사용 흐름을 점검하는 과정까지 참여했습니다.

| 설계 | SPIM 실험 환경의 주요 상태와 관리 흐름 정리 |
| 웹 개발 | Django 기반 사용자 인터페이스 및 관리 기능 구현 |
| 서버 | 사내 서버 구성과 실행 환경 설정 |
| 검증 | 기능 테스트, 사용 흐름 점검, 개선 사항 반영 |

## 구현한 기능

### 실험 환경 관리 화면

실험자가 현재 환경을 빠르게 확인할 수 있도록 관련 정보를 한곳에 모았습니다. 자주 사용하는 기능과 상태 정보의 우선순위를 나누어 화면 구조를 설계했습니다.

### 웹 기반 제어 흐름

장비와 관련된 작업을 웹에서 수행할 수 있도록 제어 흐름을 구성했습니다. 사용자가 실행 결과를 이해할 수 있도록 상태 변화와 피드백을 명확하게 전달하는 데 집중했습니다.

### 사내 운영 환경

개발 환경에서만 작동하는 결과물로 끝내지 않기 위해 사내 서버에 실행 환경을 구성했습니다. 이후 기능을 테스트하고 개선할 수 있는 기반을 마련했습니다.

## 문제 해결 과정

1. 실험 환경에서 반복되는 작업과 필요한 정보를 먼저 정리했습니다.
2. 장비 중심의 용어를 웹 사용자가 이해하기 쉬운 화면 구조로 변환했습니다.
3. Django를 이용해 화면과 관리 로직을 연결했습니다.
4. 사내 서버에서 실행하며 환경 차이와 사용 흐름을 점검했습니다.
5. 테스트 과정에서 발견한 불편을 기능과 인터페이스에 반영했습니다.

## 배운 점

연구 장비를 위한 소프트웨어는 일반적인 웹 서비스와 달리 실제 실험 흐름과 장비 사용 맥락을 함께 이해해야 했습니다. 기능 구현만큼 사용자가 현재 상태를 오해하지 않도록 명확한 피드백을 제공하는 일이 중요하다는 점을 배웠습니다.
