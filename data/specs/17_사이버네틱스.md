# 프로젝트 개요
사이버네틱스이미지시스템스에서 **2개월간 개발 인턴**으로 근무하며  
SPIM 현미경 실험 환경을 위한 웹 기반 제어 및 관리 시스템을 설계하고 구현했습니다.  

실험 장비 사용 편의성을 높이기 위해 Django 기반 사용자 인터페이스를 개발하고,  
실험 환경 관리 및 제어 기능을 웹에서 수행할 수 있도록 시스템을 구축했습니다.  
또한 사내 서버 환경 구축을 통해 서비스 운영 기반을 마련했습니다.

---

## 주요 수행 업무

- SPIM 현미경 제어·관리 시스템 설계
- Django 기반 사용자 인터페이스 개발
- 실험 환경 관리 기능 구현
- 웹 기반 제어 기능 개발
- 사내 서버 구축 및 환경 설정
- 시스템 테스트 및 기능 개선

---

## 사용 기술

- Django
- Python
- Web UI 개발
- 서버 구축 및 운영
- 실험 장비 제어 시스템 설계

---

## 인턴십 성과

- SPIM 실험 환경 웹 기반 관리 시스템 구현
- 연구 장비 사용 편의성 향상
- 서버 구축 및 운영 경험 확보
