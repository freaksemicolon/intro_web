# 개요
교내에서 진행된 알고리즘 챌린지에 참가하여  
자료구조와 알고리즘 기반 문제 해결 능력을 바탕으로 **금상**을 수상하였습니다.  

주어진 시간 내 다양한 유형의 문제를 분석하고  
효율적인 알고리즘을 설계하여 구현하는 과정을 수행하였습니다.

## 주요 내용

- 알고리즘 문제 풀이 대회 참가
- 시간 제한 내 최적 알고리즘 설계
- 자료구조 활용 문제 해결
- 코드 구현 및 테스트 수행
- 문제 분석 및 로직 최적화
