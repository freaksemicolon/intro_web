# 프로젝트 개요
스타트업 **SIMVEX**의 아이디어를 기반으로 실제 서비스 MVP를 제작하는  
블레이버스 MVP 개발 해커톤에 **팀장**으로 참여한 프로젝트입니다.  

팀을 구성하고 개발 방향을 설계하여 제한된 시간 내  
서비스 핵심 기능을 구현한 **MVP(최소 기능 제품)**를 제작하여 제출하였으며  
프로젝트를 성공적으로 완료하여 수료하였습니다.

---

## 주요 기능

- 스타트업 아이디어 기반 서비스 MVP 제작
- 핵심 기능 중심 서비스 설계
- 사용자 흐름 기반 UI 구성
- 빠른 프로토타입 개발
- 기능 우선순위 기반 개발 진행

---

## 내가 수행한 역할

- 팀장 (Team Lead)
- 프로젝트 기획 및 방향 설정
- 핵심 기능 정의
- 개발 일정 관리
- 팀원 역할 분배
- MVP 개발 참여

---

## 사용 기술

- Web 서비스 개발
- MVP 설계
- UI/UX 설계
- 협업 기반 개발
- 빠른 프로토타이핑
