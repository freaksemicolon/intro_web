# 프로젝트 개요
Treehouse의 **Full Stack JavaScript Track**을 수강하여  
JavaScript를 기반으로 프론트엔드와 백엔드를 포함한  
풀스택 웹 개발 과정을 학습하였습니다.  

클라이언트 사이드 UI 구현부터 서버 구축,  
데이터 처리까지 웹 서비스 전체 흐름을 이해하고  
실습 프로젝트를 통해 풀스택 개발 경험을 쌓았습니다.

---

## 학습 내용

- JavaScript 심화 문법
- 비동기 처리 (Async / Await)
- Node.js 기초
- Express 서버 구축
- REST API 개념
- 데이터 처리 및 라우팅
- 프론트엔드-백엔드 연동
