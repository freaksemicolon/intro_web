# 프로젝트 개요
카메라 기반 손 제스처 인식 기술을 활용하여  
마우스와 키보드를 대체하는 **퍼셉츄얼 컴퓨터 인터페이스**를 구현한 프로젝트입니다.  

Google MediaPipe를 사용하여 손가락 위치를 추적하고,  
각 손가락의 접힘 여부를 분석하여 마우스 클릭, 이동, 키 입력 등의 기능을 수행하도록 설계했습니다.  

또한 STT/TTS 기술을 결합하여 **음성 타이핑 및 실시간 번역 기능**도 함께 구현하였습니다.

---

## 주요 기능

### 손 제스처 기반 마우스 제어
- 검지 손가락 기반 마우스 이동
- 엄지 + 검지 제스처 → 좌클릭
- 검지 + 중지 제스처 → 우클릭
- 손가락 조합 기반 드래그 기능
- 손가락 제스처 기반 스크롤 기능

### 손 제스처 기반 키보드 입력
- 손가락 위치 좌표 저장
- 손가락 접힘 인식 기반 키 입력
- 가상 키보드 영역 클릭 처리
- 손 제스처 기반 타이핑 기능

### 음성 인터페이스 (STT / TTS)
- 음성 인식 기반 텍스트 입력
- 음성 명령 처리
- 음성 타이핑 기능
- 텍스트 음성 출력 기능

### 실시간 번역 기능
- 음성 언어 자동 인식
- 한국어 실시간 번역
- 번역 결과 음성 출력
- 웹 입력 위치 자동 텍스트 출력
